# Nexus Game Kit Test Runs

External validation harness for Nexus Game Kit.

This repository is separate from the publishable NexusGameKit package repo. The package repo owns the Unity Editor control surface. This repo owns the validation harness layer.

## Current baseline

- Python payload harness.
- Local payload checks.
- Runner client utilities.
- Report writer.
- Smoke payload examples.
- GitHub workflow for harness tests.
